How To Install?

1- Create a new project or use one of yours and import the asset from asset store

2- You will be warned that importing will overwrite your current project settings
	the edites settings are 1-Quality settings, 2-Player Settings, 3-Graghic, 4-Tag Manager and 5-Build Settings
	in case you import the asset onto one of your projects.

3- also the asset require Unity packages to work, Unity Text mesh pro and Unity Post processing
You will get a prompt saying "This Unity Package has Package Manager dependencies" click Install/Upgrade... this will install or update Text mesh pro and Post processing.

4- after that... you will get a list of the contents of the asset,  click Import and now you are ready to go.

WHAT IS MOST IN ONE?
A flexible toolkit that brings together a wide range of A LOT of unrelated assets,  game systems, templates, mechanics, models, design patterns, and tricks commonly used —
all in one package.
Each system is crafted to cover most real-world use cases and development perspectives.


HOW DOES IT WORKS?
This toolkit is separated into two parts 
1- Systems (Generally the MOST Systems)
Most systems are built to be fit for all game types that this system can work on
each MOST system has 3-6 examples with different variations to show how you can customize the system to fit your vision
also, MOST systems are just one single .cs file and fully independent as well as other systems and assets of MOST IN ONE,
you can copy/paste any most system to your game and it will work as expected (just remove MOST namespace)
by eliminating the need for complex configurations

2- Templates (Showcase of a certain game behavior or examples built by MOST Systems)
each template aims to showcase one or more MOST Systems or show a common aspect of game creation, also,
prefabs and assets are built to be fit for all game types that this system can work on + fully independent.

the point of this asset is to make a lot a lot a lot of things, anything (Systems, sub Systems, Templates, Prefabs,  effects, behaviors, ........)
and you can just drag/drop the "thing" you want to use in your project and done. no complex scripts, menus, dependencies, core files, or this hard stuff for beginners.

all demos core built using these most systems
check these demos and also https://solo-player.gitbook.io/most-in-one/

you can use any of these systems in your project easily by just add the system to you objects
